# CareCadence source register

- Registry version: **2026-07-21**
- Last verified: **2026-07-21**
- Authoritative code: `src/server/sources/registry.ts`

This register catalogs source metadata. It does not define who is eligible for a service, when a service is due, which method qualifies, or how a result changes follow-up. Those decisions require a separately reviewed, versioned rule record with scenario tests. External prose and MyHealthfinder responses must never activate or modify medical logic automatically.

## Governance boundaries

- Federal baselines use final USPSTF recommendations and the operative CDC/ACIP schedule sources.
- Specialty society sources remain labeled alternatives. Their ages, intervals, and methods are never blended with a federal variant.
- Draft, future-effective, and retired sources remain inspectable but cannot silently replace a current source.
- A stale review date means review is due; it does not by itself mean the source or active reviewed rule is invalid.
- A changed external-content hash is stored as `changed_unreviewed`. The prior revision remains available, and active rules do not change.
- MyHealthfinder is consumer explanation content only. Calls use an anonymous allowlist, cached copies show their fetch date, and imported text is displayed inside a distinct source-supplied boundary with required attribution.
- Internal reviewer notes live in seed metadata and are removed from public metadata.

## Current version decisions

- The final 2018 USPSTF cervical recommendation remains the current USPSTF source. The 2024 draft is registered but inactive.
- The HRSA women’s preventive-services update published in 2026 is future-effective for plan years beginning in 2027. It cannot back an earlier active rule.
- The operative CDC adult immunization baseline is the July 2, 2025 schedule under the current federal injunction boundary, together with the separately reviewed April 27, 2026 RSV amendment. Live page changes require review.
- The CDC 2023 universal hepatitis B screening recommendation is a distinct source variant from the risk-based 2020 USPSTF recommendation.
- The ACS breast and cervical sources and the 2026 ACC/AHA dyslipidemia guideline are specialty alternatives, not default federal rules.

## MyHealthfinder attribution and privacy contract

Only `age`, `sex`, optional `pregnant`, optional `sexuallyActive`, optional `tobaccoUse`, and `language` may enter the v4 request. Date of birth is converted to age locally. Names, emails, user/profile/household IDs, exact dates of birth, notes, medications, attachments, document metadata, and arbitrary extra keys are rejected before a request is made.

Where MyHealthfinder content appears, CareCadence must:

1. Link the required MyHealthfinder logo to `https://odphp.health.gov/myhealthfinder`.
2. Display the source content’s last-updated value.
3. Keep source-supplied content separate from CareCadence-authored summaries.
4. Sanitize HTML without executing scripts or accepting event handlers, inline styles, unsafe URL schemes, or active embeds.
5. Show when a cached fallback was fetched.
6. Preserve the prior revision and require review when a content hash changes.

## Operator commands

```bash
pnpm sources:verify
pnpm sources:verify --live
pnpm sources:verify --json
pnpm sources:report
pnpm sources:report --json
pnpm sources:sync
```

`sources:verify` is structural and offline by default. `--live` is an explicit maintainer check; an unreachable site is reported without making ordinary CI depend on the public internet. The sync command uses database-backed source cache and sync logs. `--file-cache` is available only for an operator-controlled standalone cache file under the private upload directory.
